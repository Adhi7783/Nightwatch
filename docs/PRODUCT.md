# Product decisions

Nightwatch is built around a simple detective loop: discover, compare, connect, and conclude. The original case, The Midnight Museum Heist, has ten clues, three suspects, and one authored explanation.

## A complete case

One carefully bounded mystery keeps the story coherent and allows the evidence, motive, method, and reveal to support each other. Additional cases can expand the catalog later without replacing the current investigation.

## Cooperation without losing control

The investigators share evidence, notes, and card arrangements while keeping independent cameras. A partner's contribution should be visible without forcing the other person to look somewhere else. Short drag reservations and optimistic concurrency checks make overlapping edits explicit.

## Evidence before automation

The board records theories without grading every relationship. Accusations are validated by deterministic server rules. The evidence assistant selects source-checked observations instead of generating deductions. This keeps the central detective work with the players.

## Integrations with a purpose

ElevenLabs provides a brief, timed opening. Anthropic helps investigators revisit earned evidence. CloudConvert turns the completed case into a portable report. Each feature adds a specific capability, and the core investigation remains usable when a provider is unavailable.

## Focused scope

The current release includes a bounded thirteen-card canvas rather than a general whiteboard. Freehand drawing, cursor trails, achievements, monetization, and generated mysteries are outside its scope. The next useful expansion would be another authored case with independent playtesting.
