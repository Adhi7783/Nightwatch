# Playtesting guide

Use separate signed-in accounts for a cooperative playthrough. Read the case without opening the server solution first.

## Start and return

- Create a case through the confirmation dialog, or choose Resume case.
- Confirm that the opening voice and text remain synchronized.
- Invite one partner before starting, then begin from the host account.
- Refresh both sessions and verify that the room and evidence persist.
- Delete a personal save, then use Undo. Check that the partner's save is unchanged.

## Investigate together

- Open each location and share its evidence.
- Review a clue and mark another important.
- Move different cards simultaneously and check that both positions persist.
- Try moving the same card and confirm that the reservation is visible.
- Draw, label, edit, remove, and undo a connection.
- Attach a note to a clue and verify it from the other account.
- Check list view, tap-to-connect, keyboard controls, and smaller screens.

## Reach a conclusion

- Submit an unsupported or incorrect theory and check that it stays spoiler-safe.
- Submit matching supported conclusions from both investigators.
- Read the complete reveal and inspect the exported PDF.
- Resume the closed case and confirm its history is preserved.

Record the browser, viewport, steps, expected result, and observed behavior for any issue. Use fictional test data and keep credentials out of reports.
